
# MiniDB: Упрощенная СУБД на Java

## Описание
Лабораторная работа №2. Консольная система управления базами данных на Java. 
Программа умеет создавать таблицы, добавлять/удалять/изменять записи, выполнять поиск с фильтрацией и сохранять данные на диск. 
Реализована поддержка индексов для ускорения поиска и сериализация через JSON (библиотека Jackson).

## Архитектура системы

Код написан с разделением ответственности: логика хранения отделена от интерфейса и парсинга запросов.

Структура классов:

```text
[MiniDbApp] (Консоль) 
    |
    v
[QueryParser] (Разбор SQL-строк)
    |
    v
[DatabaseEngine] (Ядро: хранение, индексы, запись в файл)
    |
    +-- [TableSchema] (Описание таблицы: имена колонок, типы)
    +-- [Row] (Одна строка данных)
```

Как работает вставка (INSERT):
1. Пользователь вводит команду в консоли.
2. Парсер разбирает строку, выделяет имя таблицы и значения.
3. Движок проверяет уникальность первичного ключа.
4. Если всё хорошо - добавляет строку в список и обновляет индексы.
5. Данные сразу сохраняются в JSON-файлы на диске.

## Результаты тестирования производительности

Тестировала на таблице из 10 000 записей (поля: id, name, year, price). Замеряла время через System.currentTimeMillis().

| Операция | Время | Комментарий |
| :--- | :--- | :--- |
| SELECT без индекса (year=2020) | ~7 мс | Полный перебор списка |
| SELECT с индексом (year=2020) | ~3 мс | Поиск по HashMap (ускорение ~2.3x) |
| Генерация 10 000 записей | ~34 517 мс | Медленно из-за записи в файл после каждой вставки |

**Выводы по тестам:**
Индекс дал ускорение примерно в 2 раза. 


## Инструкция пользователя

### Как запустить
1. Откройте проект в IntelliJ IDEA.
2. Проверьте, что подключена библиотека Jackson.
3. Запустите класс minidb.MiniDbApp.
4. Вводите команды в консоль. Для выхода напишите exit.

### Примеры команд

Создание таблицы:
CREATE TABLE books (id INT PK, title STRING, author STRING, year INT, is_available BOOL);

Вставка данных:
INSERT INTO books VALUES (1, 'Clean Code', 'Robert Martin', 2008, TRUE);
INSERT INTO books (id, title) VALUES (2, 'Effective Java');

Поиск:
SELECT * FROM books;
SELECT title, author FROM books WHERE is_available = TRUE;

Индексы:
CREATE INDEX idx_year ON books (year);
SELECT * FROM books WHERE year = 2008; 

Изменение и удаление:
UPDATE books SET is_available = FALSE WHERE id = 1;
DELETE FROM books WHERE id = 2;
